# ¿Qué es UML y para que sirve?

UML o Lenguaje de Modelado Unificado es como un estándar o un idioma común que usan los programadores para dibujar planos de cómo funciona un software, sin importar si programa en Java o Python, pueda entender la estructura de un sistema solo viendo los dibujos , ayuda a visualizar las clases, sus atributos y cómo se relacionan entre ellas antes de escribir el código real asi evitando errores de diseño.
